# Release Notes

> 面向用户的版本变更日志。
>
> **维护规范**:
> - 每个版本平铺若干条目，按模块合并相关变更（一个模块的新增 + 修复 + 优化合为一条）
> - **只写用户可感知的变更**：不出现函数名 / 行号 / 内部机制 / 代码级步骤；不被用户察觉的重构、依赖升级、内部优化不写


## [0.7.13] — 2026-09-05

- 新增**自动更新后台静默下载**功能。
- 新增**字体选择**功能：设置面板外观分组新增西文字体、中文字体、等宽字体三个设置项。
- 行号从全局设置开关改为代码块增加行号显隐按钮。
- 修复若干已知问题，优化编辑器体验。
- *新增 Linux AppImage 构建，适配统信 UOS V20*。


## [0.7.12] — 2026-08-23

- 新增全局缩放功能，支持 `Ctrl+Shift+=` 放大、`Ctrl+Shift+-` 缩小、`Ctrl+Shift+0` 重置与设置面板滑块缩放；`Ctrl+=` / `Ctrl+-` 改为提升 / 降低标题级别。
- **版本历史**优化：diff 语义从「与当前内容对比」改为「与前一版本对比」；快照保留数提升到 50 个并增加 30 天过期清理；dirty 时列表头部显示「未保存」虚拟条目。
- 新增**Git 历史集成**功能：文件在 Git 仓库中时，版本历史面板自动加载 Git commit 历史与本地快照合并展示，悬停查看完整提交信息；
- 新增**Hot Exit 崩溃恢复**功能：异常退出后重启自动提示恢复未保存内容，按工作区隔离。


## [0.7.11] — 2026-08-17

- **设置 > 系统** 新增「GPU 硬件加速」开关
- **命令模式**优化：新增命令面板暗色 / 浅色快捷切换命令，无打开文档时隐藏依赖文档的命令
- **更新卡片**优化，增加版本校验和实时下载速度显示，修复点击「下载并安装」后更新卡片直接消失的问题
- 修复打开大文档时加载遮罩永久卡住的问题


## [0.7.10] — 2026-08-13

- 新增「本地版本时间线」功能：每次保存创建版本快照，保留最近 20 个状态。侧栏新增「版本历史」面板浏览历史快照，点击条目查看行级 diff 对比，支持版本恢复。命令面板增加「浏览版本历史」。

## [0.5.1] — 2026-06-24

### Added
- **文件树可见图片文件**：文件树现在同时显示 `.md`/`.markdown`/`.mdown` 与图片文件。
- **文件树拖入编辑器**：文件树中的任何文件行现在都可以拖入编辑器区域。
  - 拖 `.md` 文件：打开到编辑器
  - 拖图片文件：复制到当前文档的 `assets/`，并在 drop 位置插入图片。
  - 源码模式行为镜像富文本模式：拖 `.md` 打开文件，拖图片在光标处插入 `![alt](src)`。

- **文件夹“在 Velo 中打开”右键菜单（Windows）**：首次启动自动注册文件夹右键菜单，点击以该文件夹为工作区启动 Velo。
- **文件树空白处双击/右键新建文件**：空白处双击新建 MD 文件，右键弹“新建文件 / 新建文件夹”菜单。
- **文件树右键菜单新增“在编辑器中打开” / “作为工作区打开”**：右键 `.md` 文件可“在编辑器中打开”，右键子目录可“作为工作区打开”。

### Changed
- **根节点纳入文件树**：根节点作为文件树第一行渲染，可右键弹根上下文菜单。
- 文件树新建 / 重命名输入框跟随主题色。
- 空目录不显示展开箭头。

## [0.4.0] — 2026-06-13

### Added
- **图片粘贴 / 拖拽落盘**：保存到 `<fileDir>/assets/`（已保存文档）或 `<appDataDir>/assets/`（未命名文档），markdown 使用相对路径便于文档迁移。

- **设置持久化**：字号 / 主色 / 字体 / 暗色 / 代码块主题 / 自动保存等全部持久化。

- **语法支持**：任务列表 `[ ]` / `[x]` 编辑器内点选切换；脚注渲染、Ctrl / Cmd+点击跳转 def、def 末尾回链 ref。
- **状态栏**：字数 / 词数 / 行数。
