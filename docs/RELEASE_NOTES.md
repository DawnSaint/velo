# Release Notes

> 面向用户的版本变更日志（中文）。
>
> **维护规范**:
> - 按 [Keep a Changelog](https://keepachangelog.com/) 格式 + [SemVer](https://semver.org/) 记录版本变更，分组：Added / Changed / Deprecated / Removed / Fixed / Security / Dependencies，按需选择
> - 内容粒度：能让用户"看懂这个版本加了/改了什么"即可
> - **只写用户可见的事项本身，不写背后的实现细节**：不出现函数名 / 行号 / 内部机制 / 代码级步骤；实现取舍进 DECISIONS，踩坑进 ARCHITECTURE


## [0.7.2] — 2026-07-17

### Added
- **下划线语法**：支持 `<u>text</u>` 下划线 mark —— 键入 `<u>` 标签实时转换，`Ctrl+U` 快捷键切换下划线，光标进入下划线范围自动展开为源码字符编辑。
- **行内 HTML 标签点击展开源码编辑**：行内 HTML 标签点击后展开为原始 HTML 源码文本，光标移出自动提交重建节点，Escape 还原；提交时校验标签平衡，残缺标签退化为纯文本。
- **块级 HTML 源码切换按钮**：块级 HTML（`html_block`）右上角加源码切换按钮，点击替换为 `html` 代码块进入源码编辑，光标移出自动提交重建为 HTML 块，Escape 还原。
- **HTML 块内独立 `<img>` 标签适配为原生图片节点**：HTML 块中独立的 `<img>` 标签（含 src/alt/title/width 等属性）自动转为原生图片节点，支持选中、源码编辑与 Tauri 本地图片代理；嵌套在 HTML 结构内部的 `<img>` 在渲染层代理图片路径，不再裂图。

### Changed
- **折叠占位符交互优化**：折叠后的 `...` 光标可自然停在两侧、可被鼠标划选覆盖；选中后按删除键连同折叠内容整块删除。


## [0.7.1] — 2026-07-17

### Added
- **表格编辑**:表格现在支持完整的键盘 + 鼠标交互 —— 列宽拖拽、行/列增删(快捷键 `Ctrl+Shift+↑↓←→` / 右键菜单 / 行左侧与列顶的灰色拾取条)、行/列移动(整块推,触边取消)、撤销后光标落到正确位置。
- **矩形批量操作**:在表格内拖蓝选中若干 cell(飞书风格,行列拾取条可拖拽框选整行 / 整列)后,右键菜单对齐 / 增删 / 移动的锚定为矩形覆盖区域 —— 对齐覆盖的所有列一起变、删行删掉矩形覆盖的所有 body 行(全删=删表,保底留一行)、删列保底留一列、点击拾取条之间的空白处取消选中。
- **表格剪贴板**:选中多个 cell 后 `Ctrl+C` / `Ctrl+X` / `Ctrl+V` 走矩形块语义(复制为 tab 分隔文本,对齐 Excel / Google Sheets 粘贴格式;粘贴按矩形边整块填充,不拆不乱);支持 Excel / Sheets / 浏览器复制表格时剪贴板同时含 `<table>` + TSV + PNG 的场景 —— 自动识别为表格并以规整的 `<table>` 节点插入,不再误插图。

### Changed
- **表格溢出与样式**:表格容器改为横向滚动 + 现代样式(圆角 / 边框 / 贴合深色模式),列柄与拾取条容在编辑器滚动容器内,侧栏开合后自动重对齐。


## [0.7.0] — 2026-07-11

### Breaking Changes
- **Windows 安装器从 MSI 切换为 NSIS**：安装路径从 `Program Files` 迁至 `%LOCALAPPDATA%\Velo`（per-user only）；新安装器内置自定义界面与选项页。
- **右键菜单改为 opt-in**：安装时可勾选「文件夹右键显示"在 Velo 中打开"」「.md 文件右键显示"用 Velo 编辑"」两项。Windows 注册表写入的 ProgID `Velo.md` 保证"打开方式"列表中始终能看到 Velo。

### Added
- **设置面板新增「Windows 集成」分组**：可在设置面板开关「文件夹右键"在 Velo 中打开"」和「Markdown 文件右键"在 Velo 中编辑"」;提供「设为 Markdown 默认程序」入口,跳转到 Windows 默认应用页面由用户手动选择。
- **Markdown 右键菜单覆盖范围扩大**：除 `.md` / `.markdown` / `.mdown` 外,新增 `.mkd` / `.mkdown` / `.mdwn` / `.mdtxt` / `.mdtext` 共 8 个常见 Markdown 扩展名。


## [0.6.7] — 2026-07-10

### Added
- **Front Matter 识别与编辑**:文档首部 `---`(YAML) / `+++`(TOML) 包裹的元数据块现在渲染为独立的「Front Matter」块,标题栏显示种类、内容可直接编辑;在文档首段键入 `---`/`+++` 后跟空格或回车即实时转换;支持 YAML 与 TOML 一键切换种类。
- **Front Matter 语法高亮与折叠**:frontmatter 内容按种类以 shiki 语法高亮,深浅色自动跟随;块可折叠。

### Fixed
- **新建空白文档在源码模式下不再多出 4 行空行**:空文档在所见即所得与源码模式下的行数现在一致。
- **heading 折叠时 TOC 不再残留,TOC 删除不再残留 `[TOC]` 文本**:折叠范围内的目录同步收起;删除 `[TOC]` 节点不再残留文本,撤销也不再跳到文档开头。

## [0.6.6] — 2026-07-09

### Added
- **分割线可选中并删除**：分割线现在可以像图片一样被点击选中（出现蓝色选中框），选中后按 Backspace 或 Delete 即可删除；方向键移到分割线位置时光标不再消失。
- **分割线拖蓝选中**：鼠标拖蓝选中包含分割线的若干段落时，分割线也会显示蓝色选中框；鼠标拖过分割线时即时高亮，无需拖到下一行。
- **图片拖蓝选中**：与分割线同理，鼠标拖蓝选中包含图片的若干段落时，图片也会显示蓝色选中框和编辑按钮。
- **公式块 / HTML 块拖蓝选中**：鼠标拖蓝选中包含公式块或 HTML 块的若干段落时，这些节点也会显示蓝色选中框；鼠标拖过时即时高亮，与图片、分割线行为一致。

### Fixed
- **示例文档 / 只读文档支持另存为**：此前示例文档和只读文档无法使用「另存为」，现在可以正常另存并自动切换为可编辑模式。
- **Mermaid 折叠时隐藏头部工具条与行号**：Mermaid 代码块折叠后不再显示头部语言栏和行号，展开时恢复显示（折叠箭头隐藏，保留语言切换与复制按钮）。
- **相邻 Mermaid 块头部错位**：修复多个 Mermaid 代码块紧邻时，后一块的头部工具条覆盖到前一块 SVG 上方的 DOM 排序问题。

## [0.6.2] — 2026-07-06

### Added
- **统一命令面板（前缀分发）**：Ctrl+P 与 Ctrl+Shift+P 合并为同一面板，输入框首字符决定模式 —— 无前缀查找文件、`>` 运行命令、`@` 跳转当前文档标题、`:` 跳转行号；两个快捷键打开同一面板，仅预填前缀不同。`#` 工作区符号暂未实现，留待后续版本。
- **`@` 符号模式**：在命令面板输入 `@` 列出当前文档的标题树，模糊过滤后回车跳转，跨所见即所得 / 源码模式定位。
- **`:` 行号模式**：输入 `:` 加行号实时滚动到目标行并高亮，回车确认跳转；Esc 或关闭面板恢复原光标与原编辑模式。
- **文件模式「没找到 → 新建」**：查找文件时若输入的名字无任何匹配，列表顶部出现「新建文件: <name>.md」，回车即在工作区创建并打开。
- **前缀介绍行**：文件模式空查询时，面板顶部列出 `>` / `@` / `:` 三种模式入口，选中即填入对应前缀切换模式。

### Changed
- **命令面板去掉背景遮罩并上移**：面板浮层不再覆盖半透明遮罩，整体上移一段距离，便于查看下方编辑器内容。

## [0.6.1] — 2026-07-06

### Added
- **打字机模式**：开启后光标锁定在视口垂直中线，键入 / 移动光标时文档在光标下方滚动（打字机感）；文件菜单 / F9 / 命令面板入口，可与专注模式叠加，不持久化（运行时态）。
- **专注模式**：开启后当前段落外的内容降透明度，聚焦当前段落；文件菜单 / F8 / 命令面板入口，可与全屏模式叠加，不持久化。
- **全屏模式**：F11 切换全屏；文件菜单与命令面板（Ctrl+Shift+P）提供入口。
- **保持窗口最前**：文件菜单新增「保持窗口最前」开关，勾选时窗口置顶。
- **左侧功能栏可自定义**：可拖拽重排功能栏各项、右键隐藏不常用项或重置为默认；布局全局持久化（不随工作区变化），设置项固定在底部不可拖拽 / 隐藏。

### Fixed
- **打开非空文档不再自动跳到末行**：此前以空段落结尾的非空文档开屏会被拉到文档末尾（与打字机模式叠加时尤为明显）；现仅整篇为空的新建文档才在末尾聚焦以便直接开始打字，非空文档停在开头。

## [0.6.0] — 2026-07-06

### Breaking Changes
- **编辑器多标签**：单窗口内同时打开多个 `.md` 文件，顶栏标签条横排呈现，点击切换、拖拽重排；中键关闭、关闭脏盘弹确认；每个标签独立的文件路径 / 内容 / 光标 / 滚动 / 折叠 / 源码模式 / dirty / lastSavedContent。

### Added
- **全局搜索支持替换**：侧栏搜索面板顶栏新增折叠的替换行，可对命中执行「替换 / 全部替换」；状态区显示已替换处数与跳过 / 失败文件数。
- **在文件夹中搜索**：文件树右键菜单新增「在此文件夹中搜索」（仅目录节点），把搜索范围从工作区根收窄到指定子目录；面板 header 显示当前 scope 与清除按钮。
- **标签右键菜单**：标签上右键可执行「关闭 / 关闭其他 / 关闭右侧 / 关闭已保存 / 全部关闭 / 复制路径 / 在文件树中定位」。
- **标签持久化**：每个工作区独立记忆上次打开的标签集与活动标签；切工作区不应用新 workspace 的标签，重开应用还原上次标签集；启动恢复改为并行批量打开。

### Changed
- **顶栏布局调整**：顶栏恢复全局横跨整个窗口顶部的形态，logo 段固定为 48px 不与侧栏宽度联动；ActivityBar / 左侧功能区从原本「接顶到状态栏上方」改回顶栏下方中间一格（v0.6.0 多标签引入时的形态）。
- **「文件」下拉按钮合并入口**：原左侧「文件」操作面板、原顶栏「最近文件」菜单与开发模式「欢迎」按钮统一合并到「文件」下拉面板；「最近文件」条目右侧带箭头，点击展开右侧子菜单展示最近文件列表。下拉菜单与子菜单视觉 / 交互与标签 / 文件树右键菜单一致。

### Removed
- 「示例文档」入口不再从「文件」菜单中提供。
- 顶栏的「最近文件」与开发模式「欢迎」按钮已合并进「文件」下拉。

### Fixed
- **标签持久化导致 dev 启动卡死与同文件双 tab**：之前版本会把标签列表搬到工作区持久化配置，含同路径重复项；启动恢复时批量打开会把同一文件创建多个标签，TabBar 渲染量过大时会拖死 WebView2 主线程（表现为 dev 进入卡死、无法打开 devtools）；现在标签列表落盘前会去重并加数量上限，启动时若发现已开则跳过重复加载。
